## `operating.principles`

```txt
01. Make the system understandable before making it clever.
02. Treat performance as a design constraint, not a late optimization.
03. Prefer boring reliability where users depend on the result.
04. Use aesthetics to reduce friction, not to decorate confusion.
05. Write about what broke, what worked, and what the tradeoff cost.
```
