## About

Full-stack and systems engineer with 3+ years building production software across the entire stack — from React frontends and Go microservices to Rust-powered storage engines and embedded systems. I care about performance, correctness, and clean abstractions.

Currently exploring: low-level graphics, embedded systems, and the history of computing.

Outside engineering, I study **mathematics, physics, economics, finance, and management** — because the best technical decisions are never purely technical.
